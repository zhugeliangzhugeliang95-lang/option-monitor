# 在另一台电脑运行

整理日期：2026-10-21。此包是当前程序的源码交付包，首次启动需联网安装依赖，不是免安装应用。

## 包含什么

- 前端、Python 后端、富途只读行情接入、数据库迁移、测试与依赖锁定文件。
- 21 个支持标的、美股七巨头快捷切换、橙色正股参考线。
- 历史模拟盘：正股和期权各 100,000 美元，独立计算；没有券商下单接口，也没有前向自动交易。
- samples/ 和 seed_demo.py 是可选演示素材，不会自动加载。正常启动不会生成虚拟行情。

本包不包含本机 .env、登录信息、行情数据库、监测配置记录、历史报价、模拟盘回放记录、缓存及已安装依赖。新电脑首次启动是空列表，需要重新添加标的；旧电脑原有数据不受影响。

## macOS：推荐步骤

1. 安装 Python 3.12 或以上版本、Node.js 20.9 或以上版本。本项目已有验证环境为 macOS Apple Silicon、Python 3.14、Node.js 24；新电脑优先使用相同大版本。
2. 把压缩包完整解压到普通可写文件夹，不要在压缩包预览里运行。
3. 打开终端，输入 `cd ` 后把解压后的 option-monitor 文件夹拖入终端，回车。
4. 执行：

```bash
bash scripts/dev.sh
```

脚本会创建独立 Python 环境、安装 Python/前端依赖、初始化数据库，并启动前端、API 和单个行情采集进程。首次安装可能需要几分钟。保持终端打开，访问终端打印的网址；默认 http://127.0.0.1:3000，端口占用时自动选择备用端口。按 Ctrl+C 停止。

也可双击根目录的 `启动监测台.command`。若解压工具丢失执行权限，可先执行：

```bash
chmod +x 启动监测台.command scripts/dev.sh
```

想继续使用原电脑的 3100 网页端口：

```bash
FRONTEND_PORT=3100 BACKEND_PORT=8100 bash scripts/dev.sh
```

## Linux / Windows

Linux 可在安装上述 Python、Node.js 和 Python venv 支持后使用相同命令。Linux 未在本次交付中做整机验证。

Windows 当前不能直接用 PowerShell/CMD 运行这套启动器：采集锁和进程管理使用 POSIX 功能。请在 WSL2 Linux 环境内安装 Python、Node.js、解压项目并执行上述命令，不要复用 Windows 的虚拟环境或 node_modules。Windows/WSL 未在本次交付中验证。OpenD 必须能从该 Linux 环境连接；若 OpenD 在 Windows 宿主运行，默认 127.0.0.1 是否可达取决于 WSL 网络配置，请按实际地址配置，不要将 OpenD 暴露到公网。

## 接上真实行情

1. 在新电脑安装并打开富途 OpenD，使用已开通行情权限的账号登录。原电脑的登录状态不会随源码迁移。
2. 默认地址为 127.0.0.1:11111。需要修改时，复制根目录 `.env.example` 为 `.env`，修改 `FUTU_OPEND_HOST` / `FUTU_OPEND_PORT`，再重启程序。不要把账号密码填入项目。
3. 页面点击「连接富途」，添加标的，在「监测配置」设置所需档数并测试连接。新建时两侧档数为 0，需要明确设置，例如下侧 3 档、上侧 3 档。
4. 选择实际存在且尚未到期的期权到期日，并填写所需定价时间假设。不要照搬旧电脑 2026-10-19 的过期合约。程序不会自动换月。
5. 等待后台取得真实报价。开通权限、连接成功不等于报价一定新鲜；缺失、过期、不同步的报价会显示相应状态。

支持标的：SPY、QQQ、IWM、DIA、AAPL、MSFT、NVDA、AMZN、META、GOOGL、TSLA、AMD、AVGO、NFLX、PLTR、COIN、JPM、BAC、XOM、GLD、SOXX。

富途接入细节及官方资料链接见 `docs/FUTU.md`。其中历史实测记录只说明旧电脑当时的结果，不代表新电脑已连接。

## 数据和模拟盘

运行后会在项目 `data/` 下生成本机数据库。空数据库没有可回放行情，因此新电脑不会显示旧电脑的模拟收益记录；需要先采集真实行情，再选择有数据的交易日回放。模拟盘规则见 `docs/PAPER_TRADING.md`。

如需搬迁旧历史，应另外进行数据库备份迁移，不要复制仍在运行中的 SQLite 主文件而遗漏 WAL。本源码包没有携带旧数据库。

## 常见问题

- 找不到 python3 或 npm：先完成 Python / Node.js 安装，再重新打开终端。
- 安装依赖失败：检查网络与报错；锁定依赖需要从包仓库下载，压缩包不包含离线安装包。
- 指定端口被占用：关闭自己的旧启动窗口，或使用其他空闲端口；不需要结束无关应用。
- 网页有界面但无价格：先检查 OpenD 登录、行情权限、合约到期日、档数和报价时间。
- 新电脑架构与旧电脑不同：重新安装依赖，不能复制 .venv 或 node_modules。

## 自检

从项目根目录执行：

```bash
(cd backend && ../.venv/bin/python -m pytest -q)
(cd frontend && npm run typecheck && npm run build)
```

首次启动脚本完成依赖安装后才能执行上述命令。测试通过不等于 OpenD 已登录或已经取得盘中新鲜报价。
