# 最近有效到期日（2026-10-26）

新建监测 API 默认 `expiryMode=nearest`、`timeRule=expiryClose`。历史配置不静默改写，原来的 sameDay / manual 仍按原规则处理；本机已有活动监测本次通过新增配置版本切换。每份快照保存 selectedExpiration，结果及精简接口均返回实际 expiration。

- 从供应商真实到期日列表中排序选择最近有效日期；当天常规收盘前可以选当天。
- 使用配置的交易所日历判断有效交易日和常规收盘（含半日市、夏令时）。到收盘时跳过当天，周末顺延至真实列表中的下一期。
- 这是明确的研究定价/滚动规则，不代表已核验的期权最后交易或行权截止时刻。某些合约可能在正股收盘后仍可交易，本规则保守地提前顺延。
- expiryClose 优先使用合约本身 pricingAt；缺失时使用所选到期日的交易所常规收盘时间计算 T，并输出 pricingReferenceAt 和假设警告。不会写入虚假的供应商合约时间、盘口事件时间或期权交易时段。
- 不使用旧配置的固定 pricingAt / remainingDays；跨日后重新解析真实到期日。
- 到期日列表尚未取得时返回 CHAIN_WARMING；无有效到期日时返回 NO_AVAILABLE_EXPIRY。最近一期缺链或缺腿时继续报告缺失，不擅自跳到更远一期。
- 富途到期日发现每批最多 3 个标的，放在已有热报价与预热之后，受现有总时间预算约束；失败标的轮转，不长期阻塞后面的标的。
- 旧行情与旧配置版本仍保留；每份结果保存实际到期日及定价参考时刻。统计检验已在 2026-10-27 移除。

页面显示“到期日：YYYY-MM-DD · 最近一期”。配置页可显式改回手选或仅当天；默认不需要手动更新到期日。
