# 2026-10-27 升级说明

本次版本基于主分支 45eb094（保留同事新增的 E2E 脚本），包含：

- 默认选择最近有效到期日，并随到期日滚动定价参考时间。
- 删除历史与追溯页面、原始输入查看、审计导出及锁定观察功能。
- 删除统计检验、t/p 列、相关设置和后台统计任务。
- 读取请求遇到临时网络故障或 500/502/503/504 时重试一次，恢复后清除对应读取错误；写操作不自动重发。

## 已有安装

停止原有监测台后更新代码。沿用自己的 `.env` 和 OpenD 登录；仓库不包含密钥、行情数据库、依赖目录或本机运行日志。

启动 `./scripts/dev.sh` 会自动执行迁移到 0006。0005 删除锁定观察及后续结果两张表，0006 删除分钟统计和检验结果两张表；这些专用记录不可通过降级恢复。需要保留旧功能记录时，应在升级前备份数据库。原始行情、价格结果、监测对象与不可变配置版本保留。

新建监测默认最近一期；旧监测保持原配置。要将自己的全部活动监测也切到最近一期，可在停止旧进程后运行：

```bash
.venv/bin/python scripts/select_nearest_expiry.py           # 仅显示计划
.venv/bin/python scripts/select_nearest_expiry.py --apply   # 备份配置并追加新版本
./scripts/dev.sh
```

最近一期使用交易所常规收盘（含半日市）作为明确的研究定价假设，不代表已核验的期权实际截止时间。删除统计功能不放宽行情质量检查；缺少盘口时间时质量合格均价仍可为空。

## 验证

后端：`cd backend && ../.venv/bin/python -m pytest -q`。
前端：`cd frontend && npm run typecheck && npm run build`。
读取重试回归：在项目根目录运行 `node --test scripts/test_api_client.mjs`（Node 24）。
E2E 脚本按 [说明](../frontend/e2e/README.md) 使用隔离的测试数据库；不要对真实监测库执行写入测试。
