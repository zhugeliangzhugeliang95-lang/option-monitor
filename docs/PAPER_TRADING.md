# 独立正股 / 期权模拟盘

本地历史回放，不连接券商交易接口，不启动前瞻自动订单。总研究本金 $200,000，两个子账户各 $100,000，独立持仓、现金和盈亏。模拟结果与原始行情分表保存，绝不改写原报价或给真实行情打模拟成交标签。

## 预先固定的方案 v1

- 范围：当前启用的 Futu 标的；纽约常规交易时段已保存的快照。是事后研究名单，非历史时点成分名单。
- 信号：当时配置、当时所选各档 MID 反推均价对正股 MID 的原始价差。所有选定 Call / Put 都需要通过本回放的数据检查，不因某档失效而替换更远行权价。
- 正股：正价差买入、负价差卖空，最高总敞口为净值 2 倍；单标的不超过净值 50%，最多同时 3 个头寸。
- 基础期权方向 `convergence`：正价差买 Put，负价差买 Call，选择当时所选档位中最近行权价的单腿、只买入；`follow_stock` 是对照方案（正价差 Call / 负价差 Put），不以单日较高收益倒选默认方向。
- p=0.5；b=abs(gap_bp)/25；f=max(0,p-(1-p)/b)，风险预算采用 1/4 凯利，单笔不超过子账户净值 0.5%，总在险预算不超过 2%。b≤1 不开仓；再检查预计收敛空间能否覆盖盘口价差与费用。
- 期权使用的是标的价差赔率代理，未建立 Delta/IV/theta 到权利金收益的预测关系，不能当作真正最优期权凯利。期权单笔全部权利金加开仓佣金也不超过上述单笔风险预算，避免靠20%止损放大本金。
- 止损：正股（或买入 Call / Put 所对应的标的方向）不利移动 25bp；买入期权另有权利金跌20%的条件。价差沿初始方向回落80%（含穿越零）、持仓15分钟、配置变化、15:55退出。15:30停止开仓。子账户日损失2%则停开并安排退出。
- 止损是触发条件，不是保证成交价。观察到触发后至少10秒且下一有效快照才成交；开仓等待超过60秒取消，不追补缺失时段。持仓退出等待有效报价与数量；合约退出采集池时不换合约，不虚构平仓。

## 成交与成本

信号在快照写入时可用。按写入时刻、原始快照ID排序，信号快照不得用于它自身的成交。开仓下一快照重新核对方向、价差、凯利、配置、风险和数量。

买入按 ask+$0.01，卖出按 bid−$0.01（最低0）；股票每股每边佣金$0.005、最低$1；期权每张每边$0.65，100股标准合约乘数。开仓数量不超过当时买卖两侧可见数量较小值的10%，平仓必须有足够对应侧数量。未建模队列和部分成交，因此属于假设成交。

长正股以全名义本金计8%年化融资，卖空以5%计借券费用，按实际持有秒数计；这是一项保守研究假设，不是券商账单。借券可用性未知，严格模式拒绝未经证实的卖空。税费、股息、提前行权与实物交割未建模，因此不跨越收盘强行制造收益。

交易费用扣现金；净值=现金+有符号持仓的保守平仓报价价值−未付融资费用；成交毛利−双边佣金−融资借券费用=已实现净收益。未平仓估值单独列示最后报价时间与年龄。无报价不能声称已平仓或获得可实现收益。

## 数据模式

- STRICT：REALTIME来源、事件时间齐全、报价年龄≤5秒、全套盘口时差≤1秒、确认的期权交易时段。不能通过则零成交。
- EXPLORATORY：明确假设收到的盘口有效；接收/入库时间距可用时点≤30秒，正股Last≤30秒、期权Last≤300秒。Last新鲜不证明盘口新鲜；模式不会补写bidAt/askAt。仍拒绝交叉盘口、缺档、调整合约、非100股乘数、非真实来源、过期与未来时间。
- 同日参数不调优；固定2倍、3倍成本与2倍延迟做敏感性。没有样本外、没有因果胜率证据，不年化短时样本。
- 现金不交易基准=$0（无利息）。只报告实际保存区间；无完整行情不得声称全天收益。

## 复现

项目根目录使用已有 `.venv`：

```bash
(cd backend && ../.venv/bin/python -m alembic upgrade head)
.venv/bin/python scripts/replay_paper.py --day 2026-10-19 --direction convergence --output data/paper-2026-10-19-convergence.json
```

API：`GET /api/paper/coverage`、`GET /api/paper/runs`、`GET /api/paper/runs/{id}`、`POST /api/paper/runs`（必须提供 tradingDay 和 optionDirection）。每次保存新回放，旧记录只读；含参数、模型版本、原快照ID、配置hash、数据hash、委托与逐笔成交。

数据库升级前备份，所有真实数据与备份留在本机 data/，不放进源码包。

参考：OIC [Put/Call Parity](https://www.optionseducation.org/advancedconcepts/put-call-parity)，说明交易成本、现实限制与美式期权提前行权等约束。独立方向仓位并非无风险平价套利。
