# 执行价研究室 · 独立版

根据三份附件和“前 3 + 自身 + 后 3”要求重新编写的本地程序。独立目录、独立 Python 环境、独立端口，不依赖旧监测台及其数据库。

## 启动

需要 Python 3.12 或更新版本；本机验收使用 Python 3.14.3。首次安装依赖需要联网，不需要 Node.js。

**macOS / Linux**：在本目录执行 `sh start.sh`，或在 macOS 双击 `启动研究室.command`。启动器会自动打开 http://127.0.0.1:3200/ ，服务在本机后台运行，启动窗口可关闭。重复双击不会启动重复服务。需要停止时双击 `停止研究室.command`，或运行 `python3 scripts/launch.py --stop`。

**Windows**：安装 Python 后，在本目录 PowerShell 执行 `./start.ps1`。若系统策略禁止脚本，可直接执行 `py -3 scripts/launch.py`，停止用 `py -3 scripts/launch.py --stop`。手动前台运行方式：

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 3200
```

端口冲突时，可设置 `STRIKE_LAB_PORT` 后使用启动脚本。程序仅监听本机，不提供公网服务。

## 三个数据入口

1. **富途行情**：启动器会自动安装富途 SDK。也可单独运行 `安装富途支持.command`（macOS），或使用虚拟环境 Python 执行 `-m pip install -r requirements-futu.txt`。打开并登录本机富途 OpenD，确保对应美股与期权行情权限有效。默认连接 127.0.0.1:11111，可通过 `FUTU_OPEND_PORT` 修改端口。输入标的，点击获取报价；可开启每 60 秒刷新。读取最近有效到期日期权链、正股和所选七对期权快照。失败时保留明确错误，不生成价格。仅使用行情接口。
2. **本机输入**：填写估值时刻（含时区）、到期日、年利率及剩余天数；录入或导入报价。七档选档需要正股现价，缺少现价时仍可比较给定的三个行权价。人工编辑支持成交价、买卖报价；事件时间可以通过 JSON / CSV 导入。
3. **附件验证**：GOOG 案例是附件中的历史报价，七档案例是需求中的示意值。均明确标注来源，未作为当前行情。GOOG 附件缺少现价与盘口，七档案例缺少原始期权报价，程序保留这些缺失。

首次打开自动检查 OpenD；已登录时读取 SPY 或上次使用的标的。页面打开时默认每 60 秒刷新，可暂停；关闭页面后不继续采集；连接失败会在下一周期重试。快速切换标的会等待最小取数间隔，读取期间会显示忙碌状态。保存标的、利率、取价模式、刷新偏好及人工输入草稿到当前浏览器。行情刷新保留同一标的/到期日仍存在的自选档位；到期日或标的改变则重新选中心三档。选择三档、切换取价模式会自动比较。

首次打开不自动载入示例。不同来源切换会清空当前显示，避免将历史案例误认为新报价。左侧显示 OpenD 行情权限、市场状态；报价时效及来源保留在结果上方。API 权限有效不代表每笔快照都是新鲜且同步。

## 计算规则

- 按市场时段使用正股盘前价、常规成交价、盘后价或夜盘价寻找最近行权价（页面显示具体口径；对应价格缺失时不回退其他时段），距离相同取较低档；依实际行权价顺序选前 3、中心、后 3。支持不等间距。
- 一侧不足三档时显示不足，不从另一侧补档；缺少报价的档位不被更远行权价替换。
- 每档计算 `S = Call - Put + K × exp(-rT)`；成交价 LAST 与买卖价中点 MID 独立计算。没有单独 BID / ASK 估值模式，也不在模式间回退。
- 汇总显示中位数、最小值、最大值和可计算档数；不显示均值。不完整样本的汇总有明确标注。
- 自动到期日使用最近仍有效的交易日；以 XNYS 常规收盘（含半日市）作为研究截止假设，不声称已验证每个期权的实际停止交易时间。年率为用户输入假设，ACT/365。
- 三档 Call 相对价格比较严格采用附件复制思路，并推广到不等间距；每档展示参考价、溢价率、排名和五项组合计算明细。详细公式见 [计算说明](docs/CALCULATIONS.md)。

报价缺失、合约不匹配、调整合约会阻止相应计算。事件时间缺失、过旧、不同步或倒挂盘口会标注质量问题；可计算的原始值仍展示。富途快照的更新时刻不会被冒充为独立成交/盘口事件时刻。

结果是未扣成本的相对研究估值；美式期权提前行权、股息、点差、费用与不同步报价可能影响结论。程序没有交易接口、自动下单或收益承诺。

## 导入与导出

CSV 必需列：`strike`。其余可选列：

```csv
strike,call_last,put_last,call_bid,call_ask,put_bid,put_ask,call_lastAt,put_lastAt,call_bookAt,put_bookAt
```

空价格保持缺失；时间须带时区，如 `2026-10-30T16:00:00-04:00`。CSV 使用页面上的估值设置。JSON 格式见 API 文档 http://127.0.0.1:3200/docs ，也可导入本程序导出的含原始输入研究文件。导入后的来源统一标为人工数据，避免伪造 API 来源。

点击“导出本次研究”可保存输入、计算结果、当前比较和来源。服务端只保留最近 64 份内存记录；重启后清空，请主动导出需要保留的结果。七档纯示意例没有原始报价，不能重新导入作为行情。

## 1.2 使用改进

- 开启自动刷新时，首次未登录 OpenD 也会按周期重试；完成登录后无需重开页面。
- 页面切到后台后暂停自动请求，返回时若超过刷新期限立即恢复。
- 快照年龄持续显示，超过两个刷新周期提示过旧。
- 取数/比较期间暂时锁定来源和选档操作，避免旧响应覆盖新操作；展开的报价说明在刷新后保留。
- 到期缓存立即失效，下一次取数重新选择有效期限。
- Excel CSV 的 BOM、表头空格和缺列可正常处理；重复列、多余单元格返回明确提示。
- 前端逻辑测试：`node --test tests/frontend.test.cjs`（仅开发验证需要 Node）。

## 1.3 使用改进

- 导入后继续编辑会保留合约信息和校验限制；已有合约行权价只读，换合约请新增一行。
- 修改报价会清除该报价原有的事件时间，不将人工改价冒充原始报价；原始合约属性仍保留。
- 可以选择按交易日历、指定到期时刻或人工剩余天数计算。导入后保持原来的方式，不会自动改成人工天数。
- 指定到期时刻必须落在纽约时间的合约到期日，并且不早于估值时刻；异常输入显示提示。
- CSV 不支持的列会明确报错，避免误拼列名或遗漏合约限制。需要保留完整合约属性时使用 JSON。
- 富途返回缺失或过旧报价时会显示原因；不会补造价格，也不会跳过缺价行权价去凑七档。
