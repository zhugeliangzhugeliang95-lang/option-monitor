# 附件算法与复核

## 七档汇总

先按实际行权价升序排序和去重，在给定正股价格附近选最近一档，再取它前后各三档。不以固定金额步长推断不存在的合约。

每档分别用 LAST 或 MID 计算：`S_i = C_i - P_i + K_i exp(-rT)`。MID 的 Call 与 Put 各自需要完整买卖价，不以成交价补盘口。汇总为有效结果的 median/min/max，并报告有效档数。中位数是排序后居中的值；有效结果数量为偶数时取中间两个数的平均。

需求示意：股票 130.89；行权价 123、124.5、127、129.5、133、134、135；反推值 129.33、130.11、131.06、129.18、128.98、130.51、131.02。结果为中位数 130.11、最小值 128.98、最大值 131.06。这里只验证给定结果的选档与统计，没有伪造原始 Call/Put 来反向凑数。

## 三档复制比较

对目标档 i，用另外两档 j、k：

```
w_j = (K_k - K_i) / (K_k - K_j)
w_k = 1 - w_j
C_ref_i = P_i + w_j (C_j - P_j) + w_k (C_k - P_k)
premium_i = (C_i - C_ref_i) / C_ref_i × 100%
```

权重满足和为 1、加权行权价等于目标行权价，故该复制表达式中行权价折现项消去，参考价不依赖利率。边缘目标可能产生负权重，表示公式中的空头腿。此处仅展示估值组成，不下单。

参考价非正、缺少任一所需报价或合约规格不一致时不排名。相对溢价较低者列前；排名只针对选中的三档。复制参考价也由市场报价推导，并非独立证实的“真实价值”。

附件 GOOG 2026-10-30 案例，到期日 2026-11-06：

| K | Call | Put | 复制参考价 | 相对溢价 |
|---|---|---|---|---|
|275|7.59|3.67|7.400|2.57%|
|277.5|5.85|4.72|5.945|-1.60%|
|280|4.66|6.13|4.470|4.25%|

此组下 277.5 的相对溢价最低。附件没有提供正股现价或盘口，示例不填写这些字段；5% 年率与七天只作为逐档反推的显式假设，不影响上述复制结果。
