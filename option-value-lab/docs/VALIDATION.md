## 真实 API 验证

用户完成 OpenD 登录后，行情连接成功，返回正股权限 LV3、期权权限 LV1。通过独立程序 API 验证 SPY / SOXX / GOOG 的正股、最近到期日、七对期权、LAST / MID 七档统计与比较接口。API 权限及连接成功不代表报价独立事件时间或可成交性已验证。

发现并修复：盘前 stock.last_price 仍可能是上一常规时段价格，因此按市场状态选用 pre_price / last_price / after_price / overnight_price，并显示具体口径；缺失对应时段价格时不回退其他时段。实测 SPY 正股锚点从常规 Last 759.81 改为 API 盘前价约 755.30 后，中心行权价从 760 改为 755；这些是验收时快照，不是当前报价。

原始价缺失、规格不符或复制参考价非正时，计算/排名会明确不可用，不为了展示排名而绕过规则。快照更新时间、行情接收时间和独立事件时间保持区分。

实时验收摘要位于开发机 runtime/live-validation-final.json，浏览器截图也位于 runtime/。压缩包不包含这些市场快照、日志、个人输入或账号信息。
